# Conditional LeWM audit evidence

This folder records evidence from the 2026-11-09 working-tree audit of conditional
LeWM models, encoder reuse and dataset dispatch. Keep audit findings and probe
summaries here. Implementation code and permanent assertion scripts belong in
the normal model/data/utils and tests directories.

The draft implementation specification and pending design decisions are in
[`../../specs/lewm-conditional-experiments.md`](../../specs/lewm-conditional-experiments.md).

The initial probes are diagnostic checks, not a completed training/validation/test
acceptance experiment or a benchmark result.
